harry0703/MoneyPrinterTurbo

  • 它是什么： 一个 Python 驱动的一站式 AI 短视频生成工具，可通过 AI Agent、WebUI、API 或 CLI，从主题/关键词生成脚本、配音、字幕、背景音乐和成片。它支持多种大模型、TTS 服务、本地模型网关及 Pexels、Pixabay、Coverr 或本地素材。
  • 有什么作用： 把选题、文案、素材检索、语音合成、字幕排版和视频合成串成自动化流水线，明显降低批量生产竖屏/横屏视频的操作成本。
  • 可以用于： 知识科普、营销短片、YouTube Shorts、TikTok/Reels、产品讲解、多语言内容与批量内容原型。发布前仍需核验素材许可、配音授权和平台规则，避免自动生成内容造成版权或事实风险。
  • 如何快速上手： Windows 可从 Releases 下载一键包，先运行 update.bat，再运行 start.bat；跨平台推荐 Docker：

```bash

git clone https://github.com/harry0703/MoneyPrinterTurbo.git

cd MoneyPrinterTurbo

docker compose -f docker-compose.release.yml up

```

启动后访问 http://127.0.0.1:8501，在 WebUI 配置模型、素材源和必要的 API Key；API 文档位于 http://127.0.0.1:8080/docs。

akitaonrails/ai-memory

  • 它是什么： 一个 Rust 编写的本地长期记忆服务，通过 MCP 与生命周期 hooks 捕获编码 Agent 的会话、决策和交接点，并以项目隔离的全文检索、实体关联和可选 LLM 整理提供召回。
  • 有什么作用： 让用户在 Claude Code、Codex、Gemini CLI、Cursor 等不同 Agent 或不同时间段之间续接工作，减少重复解释上下文；还提供只读 Web 页面审计和修订记忆。
  • 可以用于： 长周期软件项目、多人或多机器协作、跨 Agent 切换、阶段性交接、设计决策追溯及“几周前为什么这样做”的检索。
  • 如何快速上手： Arch Linux 可安装 ai-memory-bin；其他 Linux/macOS 用户可按 README 的 Docker 快速启动，将服务仅绑定到回环地址，再安装 MCP 与 hooks。最短接入步骤为启动官方容器后执行：

```bash

ai-memory install-mcp --client codex --apply

ai-memory install-hooks --agent codex --apply

```

若要局域网暴露服务，应先配置 Bearer Token；API Key 不应写入仓库。

  • 有什么作用： 在统一服务端点后管理多个本地模型，提高并发请求的吞吐，并用 SSD 缓存缓解内存压力；现有 OpenAI SDK 客户端可较低成本迁移到本地服务。

  • 如何快速上手： macOS 上可安装应用，或使用 Homebrew：

```bash

brew tap jundot/omlx https://github.com/jundot/omlx

brew install jundot/omlx/omlx

omlx start

```

把模型放入默认的 ~/.omlx/models，服务默认位于 http://localhost:8000/v1，内置聊天页为 http://localhost:8000/admin/chat。

  1. 网络安全、渗透、OSINT、逆向和恶意软件相关功能仅限自有系统、隔离靶场或获得明确授权的测试环境。
