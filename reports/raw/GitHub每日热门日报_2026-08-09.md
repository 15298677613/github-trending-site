## 项目分析

### 1. PrimeIntellect-ai/prime-agent

- **是什么**：TypeScript 编写的自我改进 RLM（递归语言模型）Agent，定位是编码工作流和长时间自主任务。
- **有什么用**：让 Agent 能把任务拆成可迭代步骤，保留中间状态并根据结果继续修正，适合复杂代码库操作。
- **适用场景**：长时间重构、自动修复测试、批量仓库维护、需要循环试错的研究型任务。
- **快速上手**：克隆仓库，按 README 安装 Node.js 依赖并配置模型凭据；先运行示例任务，再以只读权限测试工具调用和停止条件。
- **注意**：自我改进循环可能放大错误，生产环境应限制文件范围、网络权限、预算和最大迭代次数。

### 2. mattpocock/skills

- **是什么**：从真实 `.agents` 目录整理出的工程技能集合，面向 Codex、Claude Code、Cursor 等编码 Agent。
- **有什么用**：把调试、测试、代码审查和交付规范变成可复用的技能指令，减少重复提示词。
- **适用场景**：个人开发环境标准化、团队共享 Agent 规范、为新项目建立工程质量检查清单。
- **快速上手**：克隆仓库，按 README 将技能目录复制到客户端的 `.agents/skills`（或对应技能目录），重启客户端后按技能名调用。
- **注意**：技能会影响 Agent 行为，启用前审阅其中的命令、权限和外部服务调用。

### 6. goauthentik/authentik

- **是什么**：开源身份与访问管理平台，提供 SSO、OAuth2/OIDC、SAML、MFA、目录同步和反向代理能力。
- **有什么用**：集中处理应用登录、用户目录和授权策略，避免每个服务重复实现认证。
- **适用场景**：家庭实验室、内部工具、企业统一登录、Kubernetes 与 SaaS 的身份接入。
- **快速上手**：按官方 Docker Compose 文档部署，完成管理员初始化后创建 Provider 和 Application，再用 OIDC 或 SAML 接入一个测试应用。
- **注意**：`NOASSERTION` 表示 API 未能确认 SPDX 许可证；生产部署需单独核实版本许可和安全公告。

### 7. denoland/celld

- **是什么**：Rust 实现的自托管、分布式 Durable Objects 服务，为有状态边缘应用提供持久化对象。
- **有什么用**：把有状态逻辑部署到自有基础设施，支持对象级并发协调和持久化状态。
- **适用场景**：实时协作、房间/会话状态、边缘任务协调、对托管平台有合规要求的团队。
- **快速上手**：从 README 的 Install 方式选择二进制或容器；容器可先运行 `docker run --rm ghcr.io/denoland/celld --version`，再创建状态卷并启动单节点示例。
- **注意**：分布式部署前先验证一致性、备份、故障恢复和网络暴露面。

### 10. google/guava

- **是什么**：Google 维护的 Java 核心库，覆盖集合、缓存、并发、字符串、I/O 和不可变数据结构。
- **有什么用**：提供经过广泛测试的基础组件，减少重复实现并统一 Java 服务端代码风格。
- **适用场景**：Java 服务、数据处理、并发编程和遗留系统维护。
- **快速上手**：在 Maven 添加 `com.google.guava:guava`，或按 README 的 Gradle 依赖声明；从 `ImmutableList`、`Cache` 等模块开始，并锁定明确版本。
- **注意**：升级时阅读 API 变更和 Android/JDK 兼容性说明，避免把 Guava 类型暴露成不必要的公共接口。

- **适用场景**：浏览器内核学习、图形/编译工具链研究、开源基础设施贡献。
