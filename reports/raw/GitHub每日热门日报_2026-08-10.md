## 项目详解

### 1. PrimeIntellect-ai/prime-agent

- **是什么**：面向编码工作流和长时间自主任务的自我改进 RLM Agent，提供 TUI、持久 Goal、子 Agent 通信、心跳/计划和可控 autonomous 模式。
- **作用**：把一次性编码对话变成长任务会话；可以保留上下文、周期性重新进入任务，并把复盘结果沉淀为 prompt、skill 或 subagent 规范。
- **适用场景**：长时间评测、后台代码迁移、持续测试修复、需要人工质量门禁的 Agent 实验。
- **快速上手**：macOS/Linux 执行 `curl -fsSL https://app.primeintellect.ai/prime-agent/install.sh | sh`，然后在目标仓库目录启动 `prime-agent`；先阅读 quickstart 并配置模型凭据。
- **对 AI 客户端的价值**：可作为 Codex/Claude Code 外部的长任务编排层；重点验证停止条件、预算和权限边界。
- **注意**：安装脚本和 Agent 会执行命令、读写工作区并可能联网，生产环境应审阅脚本、使用隔离目录和最小权限。

### 2. vitali87/code-graph-rag

- **是什么**：用 Tree-sitter、多语言 AST、知识图谱和向量检索构建 monorepo RAG，带 Memgraph/Qdrant 后端并可作为 MCP Server。
- **作用**：让 Agent 按调用关系、符号和依赖理解代码，而不是只做文本相似度搜索；支持查询、定位和辅助编辑大型代码库。
- **适用场景**：跨语言单体仓库导航、影响面分析、代码问答、重构前依赖梳理、为编码客户端提供结构化上下文。
- **快速上手**：`uv tool install "code-graph-rag[treesitter-full,semantic]"`（或 pipx），准备 Docker、`cmake`、`ripgrep`；执行 `cgr daemon up`，再用 `cgr start --repo-path /path/to/repo --update-graph` 建图和查询。
- **对 AI 客户端的价值**：可接到 MCP 工具层，补足客户端的跨文件/跨语言检索能力。
- **注意**：索引可能包含私有源码；限制 Memgraph/Qdrant 的监听地址并规划数据清理，避免把源码发送到未经批准的模型端点。
