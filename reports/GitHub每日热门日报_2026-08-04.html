🤖 一、AI 编程与开发工具

1. zhaoxuya520/reverse-skill（今日热度第 1）

  • 内容：一个"逆向/渗透/安全研究"技能路由包，专为 Claude Code、Codex、Cursor、Cline 等 AI 编程客户端设计。遇到 APK、二进制、前端 JS 加密、CTF 靶场或渗透目标时，它会自动匹配方法论、检查可用工具并执行可复现的流程，而不是让 AI 瞎猜命令。
  • 作用：把"逆向/安全测试"的专家流程沉淀成可复用的技能包，让 AI 助手按规范一步步产出证据、发现、路径和报告。
  • 可用在哪些方面：安全测试研究、移动端逆向、CTF 解题、前端加密分析、代码安全审计。
  • 如何上手：把仓库克隆下来，按 README 安装依赖；在 AI 客户端中加载技能，丢给它一个 APK/二进制/CTF 题目即可。注意：仅限授权测试与学习用途。

2. esengine/DeepSeek-Reasonix

  • 内容：一个以 DeepSeek 为主的终端 AI 编程助手，单个静态 Go 二进制，围绕 DeepSeek 前缀缓存做了深度优化，长时间会话成本低；支持插件、多模型组合（执行 + 规划双模型）。
  • 作用：在终端里获得一个低成本、可常驻的 AI 编程代理，长期跑任务不烧钱。
  • 可用在哪些方面：日常编程、代码重构、长期自动化开发任务、把任意 OpenAI 兼容模型接入终端。
  • 如何上手：下载二进制，创建 reasonix.toml 配置（填 DeepSeek API Key），在终端运行即可开始对话式编程。

3. lyogavin/airllm

  • 内容：极省显存的大模型推理库。不用量化、蒸馏、剪枝，就能让 70B 模型跑在 4GB 显存上；通过"按层/按专家流式加载"技术，甚至可在 12GB 内跑 DeepSeek-V3（671B）。
  • 作用：让普通家用显卡也能跑超大模型，大幅降低本地推理门槛。
  • 可用在哪些方面：本地私有化部署大模型、研究 MoE 稀疏推理、离线知识问答、教学演示。
  • 如何上手：安装 airllm（pip install airllm），一行代码指定模型与分层加载配置即可推理，参考仓库 Quickstart 示例。

  • 可用在哪些方面：本地跑 DeepSeek 做编程助手、私有化推理服务、学习推理引擎实现。
  • 如何上手：克隆仓库，按平台（Metal/CUDA/ROCm）构建，加载对应 GGUF 模型后启动 HTTP 服务即可。
