项目详情

1. cathrynlavery/diagram-design

  • 它是什么： 面向 Claude Code、Codex 等编码代理的编辑型图表设计技能/插件，内置 29 类图表，输出自包含 HTML 与 SVG，强调清晰排版、品牌色和可继续编辑。
  • 有什么作用： 把“画架构图、流程图或比较图”变成可复用的设计流程，让代理能按统一视觉规范选择图表类型、组织信息并交付网页或文档素材。
  • 可以用于： 技术架构、产品流程、路线图、系统关系、方案对比、研究摘要、汇报配图和品牌化知识内容。
  • 如何快速上手： Codex 中执行 codex plugin marketplace add cathrynlavery/diagram-design，再执行 codex plugin add diagram-design@diagram-design；重启会话后直接说明信息、读者、尺寸和品牌颜色。第三方插件启用前应先检查 SKILL.md、脚本和权限范围。

2. semantica-agi/semantica

  • 它是什么： 面向上下文与可问责 AI 的图原生基础设施，提供上下文图、决策记录、因果链追踪、相似决策检索、数据摄取和谱系分析等能力。
  • 有什么作用： 把 Agent 的输入、依据、决定和结果组织成可查询结构，让团队不仅知道“发生了什么”，还能追溯“为什么发生、参考了什么”。
  • 可以用于： Agent 审计、合规决策记录、企业知识图谱、数据血缘、历史决策复用、Graph RAG 和需要解释性的自动化系统。
  • 如何快速上手： 执行 pip install semantica，创建 ContextGraph，用 record_decision(...) 写入决策，再通过 trace_decision_chain(...) 或 find_similar_decisions(...) 查询；连接外部数据源时把令牌放入环境变量或密钥管理器。

3. github/spec-kit

  • 它是什么： GitHub 推出的规格驱动开发工具包，把项目原则、需求规格、技术计划、任务拆分和实施流程组织成可由多种编码 Agent 执行的命令与模板。
  • 有什么作用： 在写代码之前固定“要解决什么、如何验收、采用什么方案”，减少需求漂移和 Agent 直接跳入实现导致的返工，并保留可审查的开发轨迹。
  • 可以用于： 新功能设计、遗留系统改造、团队工程规范、PRD 到代码的流程衔接、多 Agent 协作，以及受合规约束的实施计划。
  • 如何快速上手： 安装 uv 后执行 uv tool install specify-cli，再运行 specify init my-project --integration codex；进入项目后依次使用 /speckit.constitution、/speckit.specify、/speckit.plan、/speckit.tasks 和 /speckit.implement。对已有目录使用 --force 前先提交或备份并审查文件差异。

4. holaboss-ai/holaOS

  • 它是什么： 开源一体化 AI Agent 工作空间，可运行 Claude Code、Codex 和内置 Agent，并在工具、应用、浏览器、文件、技能及 100 多种集成之间共享本地记忆。
  • 有什么作用： 让用户切换不同 Agent 时复用同一套上下文和连接，减少重复配置，并把跨应用任务集中到一个桌面工作台。
  • 可以用于： 多 Agent 工作流、个人自动化、跨 SaaS 操作、浏览器与文件任务、统一 MCP 工具入口、长期项目记忆和 BYOK 模型接入。
  • 如何快速上手： 优先下载桌面应用体验；自托管前先阅读并审查仓库安装脚本，再按 README 选择一键或手动安装。连接真实邮箱、云盘和业务系统前，应逐项核对权限、密钥存储、审计日志及插件来源。

5. cactus-compute/needle

  • 它是什么： 一个约 14 MB、面向手机、穿戴设备、智能家居和机器人的端侧基础模型/工具调用运行库，可根据函数签名选择工具、补全参数并执行调用循环。
  • 有什么作用： 在不持续依赖云端大模型的情况下，为小型设备提供轻量的自然语言意图理解和函数调用能力，降低延迟、网络依赖与数据外传。
  • 可以用于： 离线家居控制、设备命令、移动端助手、机器人动作编排、低功耗自动化和隐私敏感的本地交互。
  • 如何快速上手： 执行 pip install cactus-needle；在 Python 中用 @needle.tool 装饰带类型签名和清晰 docstring 的函数，再通过 needle.Needle(tools=[...]).run("用户请求") 运行。先用只读、低风险工具评测准确率，再开放会产生现实影响的动作。

6. lightningpixel/modly

  • 它是什么： 一款完全在本机 GPU 上运行的桌面应用，可用本地 AI 从图片或提示词生成 3D 模型；桌面层以 TypeScript 为主，后端使用 Python 模型栈。
  • 有什么作用： 降低图片到 3D 资产的制作门槛，同时让素材和生成过程留在本机，适合隐私敏感或希望减少云端费用的工作流。
  • 可以用于： 游戏与 AR/VR 原型、商品三维预览、概念设计、快速建模、3D 打印前期草模和本地生成式设计实验。
  • 如何快速上手： 仓库根目录运行 npm install；进入 api 创建 Python 虚拟环境并执行 pip install -r requirements.txt，回到根目录运行 npm run dev。先核对 GPU、驱动和显存要求，并用低分辨率素材验证资源占用。

7. unslothai/unsloth

  • 它是什么： 用于本地运行、微调和部署 LLM、扩散、嵌入及音频模型的平台与 Python 工具链，也提供跨平台本地 UI，强调更快训练和更低显存占用。
  • 有什么作用： 降低 LoRA/QLoRA、强化学习、数据集构建、模型量化导出和本地服务的门槛，让个人和团队更容易完成实验到部署的闭环。
  • 可以用于： 私有模型推理、领域微调、Agent 本地后端、离线 RAG、图像生成实验、GGUF 导出和模型评测。
  • 如何快速上手： 新用户可从仓库 Release 下载 Windows、macOS 或 Linux 版本，按显存和任务选择模型；训练用户再依据官方安装器匹配 CUDA、PyTorch 与硬件环境。下载或训练前应核对磁盘、显存、模型许可证和数据合规性。

8. infiniflow/ragflow

  • 它是什么： 融合文档解析、检索增强生成、知识库和 Agent 工作流的开源 RAG 引擎，重点是把复杂文档转化为质量更高、来源可追踪的 LLM 上下文。
  • 有什么作用： 提供从文档摄取、切分、索引、召回到对话与工作流的完整链路，减少团队自行拼装解析器、向量库、检索器和 Agent 编排的成本。
  • 可以用于： 企业知识问答、客服助手、研究资料检索、合同与报告分析、内部搜索、多数据源知识同步和 Agent 应用。
  • 如何快速上手： 可先用官方云服务体验；自托管需 Docker，Linux 上确认 vm.max_map_count >= 262144，克隆仓库后进入 ragflow/docker，切换 README 推荐的稳定标签并执行 docker compose -f docker-compose.yml up -d。上线前配置鉴权、备份、模型凭据和网络边界。

9. macro-inc/macro

  • 它是什么： 面向团队的统一工作空间，把邮件、聊天、文档、任务、通话、CRM 和 Agent 通过 @ 关联起来，并共享 AI 记忆；仓库包含客户端、服务和基础设施定义。
  • 有什么作用： 减少信息散落在不同应用中的上下文切换，使人、文档、对话和任务在同一语义空间互相引用，方便 AI 使用团队级上下文。
  • 可以用于： 项目协作、客户跟进、知识沉淀、跨渠道检索、会议与邮件联动，以及带长期上下文的内部 AI 工作台。
  • 如何快速上手： 只想体验时优先使用官方产品；源码运行需 Nix 和 Docker Compose，执行 git clone https://github.com/macro-inc/macro.git、cd macro、nix develop、just run_local --no-doppler。本地依赖多、资源占用高，生产部署前应评估密钥、安全和运维成本。

10. megadose/holehe

  • 它是什么： 通过网站“忘记密码”等公开流程判断某邮箱是否在特定服务注册的 OSINT 工具，可从命令行或 Python 中调用。
  • 有什么作用： 在合法调查中辅助确认邮箱的公开服务足迹，为账号资产盘点、欺诈调查或事件响应提供线索；结果只是迹象，也可能受站点策略变化影响。
  • 可以用于： 本人邮箱暴露检查、企业自有账号盘点、经当事人同意的安全研究，以及书面授权范围内的事件响应。
  • 如何快速上手： 执行 pip3 install holehe，然后仅对自有或获授权邮箱运行 holehe name@example.com；也可用仓库 Dockerfile 构建隔离环境。禁止批量枚举陌生人邮箱、建立个人画像、绕过站点限制或把结果用于骚扰和账户攻击。

11. ToolJet/ToolJet

  • 它是什么： 开源低代码内部应用平台，社区版提供拖拽式 UI、内置数据库、多人编辑、JavaScript/Python 逻辑和 80 多种数据库、API、SaaS 与对象存储连接。
  • 有什么作用： 让团队更快搭建管理后台、仪表盘和业务流程，并保留自托管、权限控制及自定义连接器能力；企业版另提供 AI 生成、Agent 和高级治理功能。
  • 可以用于： CRM/ERP 辅助界面、运营后台、审批流、数据查询工具、客服工作台、库存管理和内部自动化。

12. smicallef/spiderfoot

  • 它是什么： 自动化 OSINT 平台，集成大量公开信息源和扫描模块，可收集域名、IP、账号、泄露、DNS 与网络资产关联信息，并形成调查图谱。
  • 有什么作用： 将分散、手工的公开信息收集流程集中化，帮助安全团队发现暴露资产、关联线索和潜在风险。
  • 可以用于： 本组织攻击面管理、威胁情报、品牌与域名监测、事件响应线索整理，以及经过授权的渗透测试前期侦察。
  • 如何快速上手： 使用稳定版或克隆仓库后执行 pip3 install -r requirements.txt，运行 python3 ./sf.py -l 127.0.0.1:5001 并从本机浏览器访问。只扫描本人资产或有书面授权的目标，不要把 Web 界面直接暴露到公网，API 密钥应存放在受控配置中。

  • 可以用于： 短视频剪辑、浏览器端编辑、桌面创作、教育内容、自动化批处理、插件开发和 AI 辅助视频工作流。

15. rustdesk/rustdesk

16. citrolabs/ego-lite

  • 它是什么： 为 AI Agent 设计的共享浏览器，Agent 在彼此隔离的 Space 中执行自动化任务，用户仍可使用自己的标签页；可通过 ego-browser 技能让 Codex、Claude Code 等调用页面能力。
  • 有什么作用： 让 Agent 复用本机登录态、Cookie、扩展和书签，同时把并行任务隔离到不同空间，减少与用户争用标签页和重复登录。
  • 可以用于： 已登录网站的资料整理、重复表单、后台操作、跨站信息收集、测试流程和多个浏览器任务并行执行。
  • 如何快速上手： 当前仅支持 macOS；可下载 Apple Silicon/Intel 应用，或执行 npx skills add citrolabs/ego-lite 安装 ego-browser 技能，首次任务会引导安装应用。之后在 Agent CLI 输入 /ego-browser 加自然语言任务。迁移 Chrome 数据会让 Agent 接触真实登录态，务必限制任务范围并对发送、购买、删除等动作保留人工确认。

  • 有什么作用： 用统一 manifest 把 Skills、Rules、MCP 服务和说明组合成可安装单元，扩展 Cursor Agent 的专业知识、工作流和外部服务连接。
  • 可以用于： 代码审查、CI 与交付、团队规范、文档可视化、多 Agent 编排、开发工具集成，以及经授权的企业 SaaS 操作。
  • 如何快速上手： 在 Cursor Marketplace 中搜索并安装所需插件；开发者可克隆仓库，查看根目录 .cursor-plugin/marketplace.json 和各插件的 .cursor-plugin/plugin.json 了解结构。连接 Gmail、CRM 等外部系统前，逐项检查发布者、权限、MCP 地址、密钥处理与每个子插件的许可证。

观察与建议

  1. 先把 Agent 的“上下文和流程”做稳。 github/spec-kit、semantica-agi/semantica、infiniflow/ragflow 分别从规格、决策图和检索上下文解决可控性问题，比单纯更换模型更接近生产痛点。
  2. 插件和共享登录态带来明显权限风险。 cursor/plugins、holaboss-ai/holaOS、citrolabs/ego-lite 能显著扩展 Agent 能力，但也扩大了数据与操作半径；应坚持最小权限、测试账号、敏感动作确认和可审计日志。
