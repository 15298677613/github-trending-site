项目详情

1. public-apis/public-apis

  • 它是什么： 社区维护的公共 API 目录，按动物、金融、天气、机器学习、开放数据等主题分类，条目通常标注认证方式、HTTPS 与 CORS 情况。
  • 有什么作用： 帮助开发者快速发现可用于原型、教学或产品集成的数据服务，减少从零搜索 API 的时间。
  • 适用方面： 黑客松和 MVP、数据采集、课程示例、第三方服务调研、测试数据与功能验证。
  • 快速上手： 无需安装。打开 README 的 Index，进入目标分类，选择 API 后阅读其官方文档；先用 curl 或 Postman 验证认证、限流和返回结构，再接入代码。公开可访问不等于可无限或商业使用，必须检查各 API 自身条款。

2. cathrynlavery/diagram-design

  • 它是什么： 面向 Claude Code、Codex 和 Pi 的图表设计技能/插件，输出自包含 HTML 与 SVG，强调编辑设计感、品牌适配和静态优先。
  • 有什么作用： 将架构、流程、循环、比较、层级等信息快速转成可直接在浏览器打开或嵌入文档的图表，降低手工排版成本。
  • 适用方面： 技术架构图、文章插图、产品说明、汇报图示、把 Mermaid 或 draw.io 草图重绘为更统一的视觉稿。
  • 快速上手： Codex 中运行 codex plugin marketplace add cathrynlavery/diagram-design，再运行 codex plugin add diagram-design@diagram-design；安装后新开会话，描述图表内容、尺寸、明暗主题和品牌色。输出发布前应检查文字、无障碍和品牌规范。

3. github/spec-kit

  • 它是什么： GitHub 推出的规格驱动开发工具包，用结构化流程让 AI 编码 Agent 先明确原则、需求和计划，再拆任务并实现。
  • 有什么作用： 把模糊需求变成可评审、可追踪的规格与任务，减少 Agent 直接编码导致的需求漂移和返工。
  • 适用方面： 新项目初始化、复杂功能设计、团队协作、PRD 到工程计划的转换，以及需要审计决策过程的 AI 辅助开发。
  • 快速上手： 安装 uv 后执行 uv tool install specify-cli，再运行 specify init my-project --integration copilot。进入项目后依次使用 /speckit.constitution、/speckit.specify、/speckit.plan、/speckit.tasks 和 /speckit.implement；其他 Agent 的集成参数与命令形式以 README 当前列表为准。

4. cordiverse/cordis

  • 它是什么： 一个 TypeScript/Node.js 元框架，围绕“时空可组合性”组织上下文、服务、插件及其生命周期；仓库由核心包和 loader、include、HMR、timer 等工作区包组成。
  • 有什么作用： 为插件化应用提供更细粒度的作用域、依赖组合与生命周期管理，让功能能够按上下文动态装载、复用和卸载。
  • 适用方面： 高度插件化的 Node.js 应用、机器人或自动化框架、长生命周期服务、需要热更新或隔离上下文的系统。
  • 快速上手： 先阅读仓库链接的 Cordis Primer，再在试验项目中执行 npm install cordis 并从最小上下文/服务示例开始。仓库明确提示 API 仍在活跃开发且不稳定，建议固定版本、补充生命周期测试，暂勿无评估地用于关键生产系统。

6. cactus-compute/needle

  • 它是什么： 面向手机、可穿戴设备、智能家居和机器人等小型设备的端侧基础模型。README 当前介绍 Needle 2：45M 参数、单个约 14 MB 引擎，专注工具调用、设备操作和结构化抽取。
  • 有什么作用： 在约束内存和离线环境中把自然语言转换为受 JSON Schema 约束的工具调用，并通过置信度决定执行或升级处理。
  • 适用方面： 端侧助手、离线控制、IoT 指令路由、结构化信息抽取、低功耗机器人以及隐私敏感的本地推理。
  • 快速上手： 执行 pip install cactus-needle，用 @needle.tool 装饰带类型签名和清晰 docstring 的 Python 函数，创建 needle.Needle(tools=[...])，再调用 agent.run(...)。首次会获取并缓存推理引擎；隔离网络部署应按仓库离线文档预置文件。

7. citrolabs/ego-lite

  • 它是什么： 为人类与 AI Agent 并行使用设计的浏览器，Agent 在独立 Space 中运行自动化任务，同时可选择复用本机浏览器登录态。
  • 有什么作用： 减少 Agent 与用户争抢标签页的问题，并通过配套 ego-browser 技能让 Codex、Claude Code 等执行已登录网站任务。
  • 适用方面： 已登录站点的重复操作、网页测试、多任务浏览、跨站信息收集和 Agent 驱动的后台工作。
  • 快速上手： 当前优先支持 macOS；可下载对应 DMG，或运行 npx skills add citrolabs/ego-lite 安装技能。安装后在 Agent 中用 /ego-browser 加自然语言任务。迁移 Chrome 数据会让 Agent 接触登录态、Cookie 和扩展，启用前必须审查任务范围、站点权限和敏感账号风险。

8. unslothai/unsloth

  • 它是什么： 用于在本地运行和训练 LLM、扩散、嵌入及音频模型的桌面应用与 Python 生态，覆盖多类开源模型、量化和微调工作流。
  • 有什么作用： 降低本地模型推理、LoRA/微调、数据准备、导出和服务化门槛，并为 Codex、Claude Code、MCP、RAG 等提供本地模型入口。
  • 适用方面： 私有 AI 助手、模型实验、低成本微调、离线推理、图像生成、研究教学和自托管模型服务。
  • 快速上手： 桌面用户直接从 README 或 Releases 下载对应 Windows/macOS/Linux 版本；开发者按官方文档选择与你的 GPU、驱动和模型匹配的安装路径。先运行小模型或官方 notebook 验证环境，再进行训练；模型许可证、显存、磁盘与数据合规需单独核对。

9. megadose/holehe

  • 它是什么： 邮箱 OSINT 工具，通过多个网站的账号恢复等公开流程，判断某个邮箱是否可能注册过相关服务。
  • 有什么作用： 在授权调查中辅助梳理邮箱的公开数字足迹，但结果可能受网站改版、反自动化和误判影响，不能单独作为身份结论。
  • 适用方面： 本人账号盘点、企业授权安全评估、事件响应与合规的 OSINT 调查。禁止用于骚扰、跟踪、撞库、未授权画像或规避平台限制。
  • 快速上手： 在隔离环境执行 pip3 install holehe，然后只对本人或书面授权邮箱运行 holehe name@example.com；也可从仓库构建 Docker 镜像。使用前应确定合法依据、最小化记录结果，并遵守目标站点条款与当地隐私法律。

10. MakazhanAlpamys/Soup

  • 它是什么： 用 YAML 配置驱动的 LLM 微调与后训练 CLI，支持 LoRA、量化、数据处理、评测、合并与多种导出方式，并主打低显存设备。
  • 有什么作用： 把分散的训练脚本和参数收敛到一个 soup.yaml，缩短从数据集到可部署模型的路径。
  • 适用方面： 消费级 GPU 微调、领域模型、工具调用数据、SFT/DPO 等后训练实验，以及向 GGUF/Ollama/llama.cpp 导出。
  • 快速上手： Python 3.10–3.12 环境执行 pip install "soup-cli[train]"，运行 soup init --template chat 生成配置，再用 soup train --config soup.yaml 训练、soup chat --model ./output 验证。低显存并不等于所有模型都可运行，开始前仍需核对模型大小、量化方案、数据授权和磁盘空间。
