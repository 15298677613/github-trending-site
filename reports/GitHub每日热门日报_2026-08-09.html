1. PrimeIntellect-ai/prime-agent

  • 是什么：TypeScript 编写的自我改进 RLM（递归语言模型）Agent，定位是编码工作流和长时间自主任务。
  • 有什么用：让 Agent 能把任务拆成可迭代步骤，保留中间状态并根据结果继续修正，适合复杂代码库操作。
  • 适用场景：长时间重构、自动修复测试、批量仓库维护、需要循环试错的研究型任务。
  • 快速上手：克隆仓库，按 README 安装 Node.js 依赖并配置模型凭据；先运行示例任务，再以只读权限测试工具调用和停止条件。
  • 注意：自我改进循环可能放大错误，生产环境应限制文件范围、网络权限、预算和最大迭代次数。
